# Roadmap

## Phase 1: MVP Foundation
- Flask project setup.
- Database models.
- Authentication.
- Dashboard.
- Room creation and joining.

## Phase 2: Collaborative Room
- Room detail page.
- Member list.
- Realtime chat.
- Shared timer events.
- Personal tasks.

## Phase 3: Study Resources
- File upload and download.
- File type validation.
- Resource list per room.

## Phase 4: Video
- Jitsi embed inside each room.
- Room-specific meeting names.
- Toggle video panel visibility.

## Phase 5: Admin And Polish
- Admin dashboard.
- User and room management.
- UI improvements.
- Empty states and validation messages.

## Phase 6: Production Readiness
- PostgreSQL.
- Redis-backed Socket.IO.
- Production WSGI/ASGI deployment.
- HTTPS.
- Cloud file storage.
- Monitoring and backups.
